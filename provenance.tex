\section*{Purpose and Conventions}

This document records the provenance of the completed evidence for paper cases
01 through 05.  The machine-readable companion file
\path{provenance_manifest.tsv} is the canonical manifest.  Each row in that file
represents one evidence package, so a case may have multiple rows when distinct
runs support performance, analytic verification, eigenpair analysis, or field
figures.

Evidence is resolved in this order: the authoritative run directory, the compact
archive, the reviewed standalone report, and the manuscript.  A disagreement
between levels is recorded as an open issue rather than silently reconciled.
``Verified evidence'' means that the listed run, archive, indexes, and figures
were found.  It does not mean that stale manuscript text has already been
updated.

verification run, not a mesh-convergence sequence.  The fixed parameters are:

\end{center}

The runner writes a timestamped authoritative directory named
\path{paper_euler_refined_verification_YYYYMMDD_HHMMSS} under the prescribed
release build.  It also creates
\path{results/euler/refined_verification_YYYYMMDD_HHMMSS} in the paper project.
The compact archive receives the exact command, parameter table, executable
metadata and SHA-256 checksum, Git commit and dirty-worktree patch, environment,
run log, response CSV, status, validation summary, runner, and validator.
The runner refuses to execute when the build system reports that
\texttt{challenge\_suite} is out of date, preventing a stale executable from
being associated with the captured source state.

For a completed run, validation requires 36 finite response states, 11200 global
elements, monotone applied force, the final two sampled forces at
$2.74\times10^{-3}$ and $2.75\times10^{-3}$, force balance within $10^{-8}$,
and the analytic Euler load inside that final interval.  A diagnostic branch
transition additionally requires lateral displacement magnitude below
$10^{-2}$ at the lower state and above $10^{-1}$ at the upper state.  These
thresholds classify the resolved jump; they are not an eigenvalue estimate or
a mesh-convergence criterion.
