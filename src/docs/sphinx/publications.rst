===============
Research Papers
===============

This page tracks research papers that use or describe Smith (formerly Serac).

Adding a Paper
--------------

If you have published work that uses Smith, please add it to this list by opening a pull request
that edits ``src/docs/sphinx/publications.rst``. Add a new entry to the list below, newest first,
using the following format:

.. code-block:: rst

   * Author One, Author Two, and Author Three.
     `Title of the paper <https://doi.org/...>`_.
     *Journal Name*, Volume(Issue):Article, Year.
