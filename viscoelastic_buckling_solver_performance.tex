\section*{Viscoelastic Buckling and Relaxation Solver Performance}

This report summarizes the unified current-code, output-enabled viscoelastic
response matrix run on \texttt{rzwhippet65} on 2026-08-17.  All eight entries and
their field output are contained in
\path{build-rzwhippet-toss_4_x86_64_ib-llvm@19.1.3-release/paper_viscoelastic_response_20260817_162546}.
Commands, logs, response histories, executable and source identity, status,

\section*{Configuration}

The three-dimensional model uses the 1097-element hemispherical-cap mesh
\path{data/meshes/cap_hemisphere.g} with quadratic displacement elements.  The
bottom boundary is fixed, and the two symmetry boundaries constrain the $x$ and
$z$ displacement components.  A scalar temperature field is fixed at 300.  The
single-branch finite-deformation viscoelastic material has density $\rho=1$,
equilibrium shear modulus $G_\infty=10^3$, branch modulus
$G_0=3G_\infty$, glassy Poisson ratio $\nu_g=0.45$, relaxation time
$\tau_0=1$, and viscosity $\eta_0=G_0\tau_0=3000$.  The glassy shear
modulus is $G_g=G_\infty+G_0=4000$, and the bulk modulus computed from
$G_g$ and $\nu_g$ is $K=38666.7$.  Thermal expansion is disabled;
$\theta_r=\theta_{sf}=300$, $C_1=0$, and $C_2=50$.

The top patch is loaded downward with a force-controlled sawtooth history.  The
nominal force rises toward 0.17 for $0\leq t<6$ and is removed at $t=6$.
Sixty time steps of size 0.4 advance the model to $t=24$, so the largest force at
an accepted state is 0.158667 at $t=5.6$.  The loaded patch area reported by the
run is 0.0764072134.  All runs use 16 MPI ranks, explicit cold starts, CG,
nonlinear relative and absolute tolerances $10^{-11}$, and linear relative and
absolute tolerances $10^{-14}$.  Hypre AMG has a 600-iteration cap and Hypre
Jacobi has a 60000-iteration cap.  Every command explicitly contains
\texttt{--no-use-bsr-spmv} and \texttt{--no-assemble-bsr}; no BSR matrix or BSR
SpMV path is used.  Every configuration writes the initial field state and every
accepted state in ParaView format.

The eight configurations combine Newton line search, PETSc Newton critical-point
line search, baseline trust region, and safeguarded trust-region subspace
globalization with both preconditioners.  All logs identify Smith version
\texttt{v0.1.0-9d4024ad9}; the executable SHA-256 checksum is
\texttt{dbc10f71d8cd7aa2a4263002924b3d8648a201bc9cda5f0b7c418ed59839e981}.
The compact archive also retains the dirty-worktree patch and the runner and
validator used for this matrix.

\section*{Response and Relaxation Validation}

All eight response histories are indistinguishable at plotting resolution.  The
largest pointwise spread is $1.0\times10^{-9}$ in average top displacement and
$6.74\times10^{-12}$ in bottom reaction; the prescribed-force histories are
identical.  At $t=5.6$, every run reaches average top displacement $-0.0198337$,
applied force 0.158667, and balancing bottom reaction 0.158667.  When the force is
removed at $t=6$, the cap rebounds to displacement $-0.0090858$ and the globally
reduced vertical reaction returns to numerical zero.

During the remaining 45 accepted states, the displacement relaxes monotonically
toward zero.  Every run finishes at average top displacement
$-1.16112\times10^{-4}$.  Final reactions range from
$-2.15\times10^{-13}$ to $3.53\times10^{-12}$, consistent with zero at the
reported precision; the largest reaction magnitude at any unloaded state is
$6.74\times10^{-12}$.  The reaction is now computed by mapping boundary vector
degrees of freedom to locally owned true degrees of freedom, summing each owned
entry once, and applying one global reduction.  The earlier implementation
summed local vector degrees of freedom directly and reduced that result again at
the viscoelastic call site.  Its nonzero unloaded value was therefore not a
valid global support reaction and is superseded by this matrix.

\section*{Solver Diagnostics and Interpretation}

No configuration fails or selects a distinct response branch.  The nonlinear
iteration totals are independent of preconditioner for each nonlinear solver, and
the baseline and subspace trust-region variants both total 203 iterations.  The
case therefore does not provide a robustness separation between Newton and
trust-region methods.  Instead, it demonstrates that approximate energetic
acceptance reproduces the same loading, unloading, and long-time relaxation path
as both Newton variants for this path-dependent material, while retaining
competitive wall time in the baseline trust-region configuration.

The subspace result is a measured overhead in this case: it leaves the nonlinear
path and iteration count unchanged while increasing wall time by $3.1\%$ with
AMG and $19.7\%$ with Jacobi.  It should be treated as a secondary
case-specific performance result, not evidence of a general regression.
